#### Отчёт

По-русски, Markdown. Разделы по порядку:

1. **Страницы** — таблица «страница — оценка читаемости из десяти — почему —
   что сделать для 10», все восемь строк; под таблицей — какие страницы
   читаются хуже остальных и почему.
2. **Пары** — по абзацу на каждую из четырёх пар: где проходит шов, держится ли
   он, помогло ли деление и насколько.
3. **Сводка** — пять–десять строк: главное, что ты увидел.
4. **Находки** — номера D1, D2, … У каждой: тяжесть; место — файл и заголовок
   раздела; что не так; почему читатель на этом споткнётся или ошибётся;
   доказательство — зонд (файл, что делает, что напечатал) или «по чтению»; что
   предлагаешь. Тяжесть: **High** — документ ведёт к неверному коду,
   до которого доходят обычным путём; **Medium** — читатель запутается или
   ошибётся в редком, но законном случае, или ссылка ведёт не туда; **Low** —
   остальное.
5. **Что хорошо и трогать не надо** — коротко.
6. **ПРОГОН** — каждая команда, которую ты действительно запустил (проверки
   и зонды), с точной последней строкой её вывода. Чего не запускал или что
   упало из-за окружения — так и напиши: «не запускал» лучше пересказа.

### 4. Находки

#### D1 — Medium: правило стека стало обещанием для любой уборки

**Место:** `packages/async_job/doc/cleanup.md`, «Choosing the callback» →
«`dispose` for what the job keeps», строки 111–129.

**Что не так.** Фраза `Cleanup callbacks run after the body ends`
распространяет правило на все колбэки. В старой версии было точное ограничение:
`The callbacks on the cleanup stack`. Соседнее обещание, что задача завершится
только после последнего колбэка, также читается без исключения для значения,
пришедшего после завершения задачи.

**Почему читатель ошибётся.** Он может рассчитывать, что `finally` тела
выполнится раньше освобождения ресурса, либо считать завершение задачи
гарантией окончания любой связанной с ней уборки. Для всех зарегистрированных
через вызов освобождений это неверно.

**Доказательство:** `packages/async_job/test/probe_split_contracts.dart`. Зонд
управляет моментом получения ресурса и завершения тела через `Completer`:

```text
join: dispose, body caught cancellation, body finally
late during body: bodyEnded=false
late after job: jobFinished=true, releaseFinished=false
```

**Предлагаю:** вернуть ограничение «callbacks on the cleanup stack». Рядом
кратко назвать немедленное освобождение при бросившей контрольной точке
и поздние результаты, со ссылками на «Registering on arrival» и «A value that
comes late». Исправляется договор текста, поведение ядра менять не требуется.

#### D2 — Medium: ссылка обещает объяснение, которое осталось на первой странице

**Место:** `packages/async_job/doc/groups.md`, «The list a group returns» → «A
`try` on the next line», строки 407–412.

**Что не так.** После утверждения, что ошибка уборщика идёт в `onError`, затем
по умолчанию в зону, стоит ссылка

**Почему читатель споткнётся.** При входе из `Guides` или dartdoc он открывает
справочник маршрутов, но должен вернуться во вступление другой страницы, чтобы
расшифровать его главную таблицу. Ссылка обозначена честно; проблема
в самостоятельности чтения, а не в неправильном поведении примера.

**Доказательство:** по чтению. Определение через `JobAnswerer.onUnanswered`
находится в первой таблице `errors.md`.

**Предлагаю:** перед таблицей дать короткое местное определение: ответ —
`onUnanswered` наблюдателя с `JobAnswerer`, иначе зона создания; стандартный
`onUnanswered` тоже направляет ошибку в эту зону. Повторять весь первый
документ не требуется.

### Находки

#### D1 — Medium: правило порядка стека распространено на все cleanup callbacks

**Место:** `packages/async_job/doc/cleanup.md:115`, `Choosing the callback` →
`` `dispose` for what the job keeps ``.

Теперь написано: «Cleanup callbacks run after the body ends». До деления
предложение явно относилось к callbacks **on the cleanup stack**.

`dispose`/`discard`, переданный `ctx.join`, может выполниться внутри этого
вызова, прежде чем тело получит отмену и выйдет через `finally`. Освобождение
позднего значения `abandonable` тоже может пересекаться с продолжающимся телом.
Читатель получает неверную гарантию порядка и может рассчитывать, что
подготовка в конце тела обязательно предшествует освобождению.

**Доказательство:** `packages/async_job/test/probe_split_cleanup.dart`. Зонд
отменяет задачу во время получения ресурса через `join`, затем завершает
получение. Отдельно проверяет позднее значение `abandonable` при удерживаемом
теле. Вывод:

```text
join arrival: discard: bodyEnded=false, body finally; Cancelled(manual)
stack: body returned, join: StateError, stack released; Done(null)
abandoned arrival: bodyEnded=false, jobFinished=false
cleanup probes: 3 passed
```

**Вердикт:** вернуть ограничение «callbacks on the cleanup stack». Рядом
коротко назвать освобождение значения, не дошедшего до тела, отдельным случаем
и сослаться на соответствующие разделы `cleanup-rules.md`. Правила неотменяемой
уборки менять не требуется.

**Место:** `packages/async_job/doc/groups.md:407`, `The list a group returns` →

```dart
Future<void> arrival() async {

  final started = Completer<void>();
  final events = <String>[];

    }
  });
  await started.future;
  final cancellation = job.cancel();
  opened.complete('database');
  await cancellation;
  require(

    'arrival order changed',
  );

}

  final events = <String>[];
  final job = Job<void>((ctx) async {
    ctx.onDispose(() async {
      try {
        await ctx.join(() async {});
        // ignore: avoid_catching_errors
      } on StateError {
        events.add('join: StateError');
      }
      events.add('stack released');
    });
    events.add('body returned');
  });
  final outcome = await job.done;
  require(

  );

  final started = Completer<void>();
  final released = Completer<void>();

  var releaseSawBodyEnd = true;

    try {
      await ctx.abandonable(
        () {
          started.complete();
          return opened.future;
        },

          released.complete();
        },

    } on Cancelled {
      await finishBody.future;
    }

  await released.future;
```

```dart
import 'package:async_job/async_job.dart';

final class Reports extends JobObserver with JobAnswerer {
  final heard = <Object>[];
  final answered = <Object>[];

  @override
  void onError(Job<Object?> job, Object error, StackTrace stackTrace) {
    heard.add(error);
  }

  @override
  void onUnanswered(Job<Object?> job, Object error, StackTrace stackTrace) {
    answered.add(error);
  }
}

void require(bool condition, String message) {
  if (!condition) throw StateError(message);
}

Future<void> cancelledFailure({required bool ignore}) async {
  final reports = Reports();
  final action = Completer<void>();
  final started = Completer<void>();
  final failure = StateError('failed after cancel');
  final job = Job<void>(observer: reports, (ctx) async {
    await ctx.join(() {
      started.complete();
      return action.future;
    });
  });
  if (ignore) job.ignoreFailure();
  final outcome = job.done;
  await started.future;
  final cancellation = job.cancel();
  action.completeError(failure);
  await cancellation;
  require(await outcome is Cancelled, 'cancellation did not win');
  require(reports.heard.single == failure, 'onError did not hear failure');
  require(
    reports.answered.length == (ignore ? 0 : 1),
    'wrong answer count after cancellation',
  );
  print('cancelled failure: ignore=$ignore, onError=${reports.heard.length}, '
      'onUnanswered=${reports.answered.length}');
}

Future<void> severalFailures() async {
  final reports = Reports();
  final first = StateError('database');
  final second = StateError('analytics');
  final answered = Completer<void>();
  final job = Job<void>(observer: reports, (ctx) async {
    ctx.unattended(() async {
      try {
        await [
          Future<void>.error(first),
          Future<void>.error(second),
        ].wait;
      } finally {
        scheduleMicrotask(answered.complete);
      }
    });
  });
  await job.done;
  await answered.future;
  await Future<void>.delayed(Duration.zero);
  require(

        identical(reports.answered[1], second),
    'failures were not unpacked',
  );
  print('parallel: onError=${reports.heard.length}, '
```

```dart
import 'dart:async';

import 'package:solo/solo.dart';

final class Probe extends Solo<int> {
  final gate = Completer<void>();
  int mergeCalls = 0;
  late final _events = accumulate<int, int, int>(
    (ctx, value) async {
      await gate.future;
      ctx.emit(value);
      return value;
    },
    merge: (value, incoming) {
      mergeCalls++;
      if (incoming < 0) throw const FormatException('negative event');
      return value + incoming;
    },
  );

  Probe() : super(0);

  Job<int> add(int value) => _events.add(value);
}

void require(bool condition, String message) {
  if (!condition) throw StateError(message);
}

Future<void> main() async {
  final controller = Probe();
  try {
    final first = controller.add(1);
    final second = controller.add(2);
    require(identical(first, second), 'different group handles');
    require(
      controller.mergeCalls == 1 && controller.currentState == 0,
      'merge did not run synchronously without changing state',
    );
    print('add: same=true, mergeCalls=1, state=0');
    var thenRefused = false;
    try {
      first.then((ctx, value) async => value);
      // ignore: avoid_catching_errors
    } on StateError {
      thenRefused = true;
    }
    require(thenRefused, 'direct then was accepted');
    print('direct then: StateError');
    var mergeRefused = false;
    try {
      controller.add(-1);
    } on FormatException {
      mergeRefused = true;
    }
    require(mergeRefused, 'merge error did not escape add');
    print('merge error: synchronous FormatException');
    final branch = first.shared();
    await branch.cancel();
    require(
      !first.isCancelled && !first.isFinished,
      'shared cancellation reached group',
    );
    print('shared cancel: groupCancelled=false, groupFinished=false');
    controller.gate.complete();
    final result = await first.value;
    require(

  } finally {
```
