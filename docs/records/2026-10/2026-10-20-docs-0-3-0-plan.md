### H1. Пробел M4 — вопрос API, строкой в документе его не закрыть

Зонд: два `run(..., key: 'load', policy: Policy.droppable)` и два `events.add`
получают одну задачу (`identical: true`); второй `then` бросает `StateError`;
`shared()` после чужого простого `then` бросает тоже; ручки `shared()`
у каждого проходят (`Done(2)`, `Done(3)`). Совет «продолжайте общую задачу
через `shared()`» работает, только если ему следуют все вызывающие ключа: один
простой `then` — законный, задача выглядит своей — и следующий вызывающий
бросает в коде, где ошибки нет, по тому, кто пришёл первым. Ровно эту
зависимость от порядка дизайн отверг для `then` (строки 142–145). Та же общая
задача уже даёт любому вызывающему отменить всю группу (`accumulation.md`
871–875) — опасность, которую M4 закрыл для `then`. Решать владельцу:
`droppable` и `add` отдают каждому вызывающему ручку `shared()` — меняет
`identical(group, same)` и отмену, показанные на `accumulation.md` и в README
125–127; или оставить, написать «не продолжайте задачу `droppable` и `add`
простым `then`» и записать решение в `docs/settled.md`. Зонд плана пропускает
смешанный случай: один `then` и один `shared()`.
