# Результат

По поручению владельца `ctx.run<T>(Job<T> child)` возвращает `Future<T>`.
Обычный вызов теперь выглядит так:

```dart
final child = Job.deferred<int>((ctx) => ctx.wait(load));
final rows = await ctx.run(child);
```

Новый Job не создаётся: исходный child остаётся хэндлом для отмены
и просмотра исхода. Метод синхронно проверяет допустимость запуска,
усыновляет ребёнка и запускает его. Затем ждёт child.value, включая
потомков и уборку ребёнка. После успеха вызывает виртуальный check
родителя перед возвратом значения, пока тело родителя активно.

Отказ или задержка отмены ребёнком не сокращают ожидание. Даже если
родитель отменён из onStart ребёнка, run дожидается окончания ребёнка.
Успешный ребёнок сохраняет Done и значение для внешнего читателя;
родитель получает свою отмену. Ошибка или Cancelled ребёнка передаются
со своим стеком по прежним правилам проброса через тело родителя.

Если тело намеренно не дождалось run и уже закончилось, поздний успешный
результат возвращается без проверки закрытого контекста, как у join.
Это не меняет структурного ожидания: родитель заканчивается после детей.

# Внутреннее устройство и перенос вызовов

Прежний синхронный запуск выделен в защищённый `startChild`. Его вызывают
run и each. each по-прежнему немедленно возвращает исходный Job<void>
и не наблюдает его исход. SoloContext переопределяет startChild для
проверки владения; виртуальный check после результата проверяет также
рабочий тип и keepWhile родителя. SoloBase.run не менялся.

Тесты и пример камеры перенесены по назначению вызова. Для значения
или проброса ошибки используется await ctx.run(child). Там, где родитель
должен рассмотреть исход и продолжить после отмены ребёнка, сохраняется
хэндл: ctx.run(child).ignore(), затем await child.done. Намеренно
параллельные запуски обрабатывают либо явно игнорируют Future от run.

Чтение child.value внутри run наблюдает исход ребёнка. Ошибкой теперь
владеет возвращённая Future; одного child.ignore() для её обработки
недостаточно. Тест зоны проверяет единственное сообщение об ошибке
Future без повторного сообщения от уже наблюдённого ребёнка.

README async_job и solo обновлены вместе с переводами, как и dartdoc,
CHANGELOG и архитектура. Новых зависимостей и изменений версий нет.
Debounce, throttle, публикация и внешние проекты в эту работу не входили.
