# Последовательное знакомство с solo

Цель: читатель впервые видит пакет и понимает его без истории разработки.
Редактируются packages/solo/README.md и packages/solo/README.ru.md.
Поведение API не меняется; примеры и существенные контракты сохраняются.

Порядок: назначение, установка, первый контроллер, результат работы,
очередь, правила состояния, отмена, внешние изменения и коррекция,
ресурсы, дети и подписки, накопление, диагностика, тесты, Flutter,
переход с bloc и пример камеры. Подробности получают свои подразделы.

Внешнее состояние объясняется через уже отключившееся устройство:
очередь может задержать уведомление за работой, которой оно противоречит.
externalSetState сразу обновляет модель и проверяет правила. Команда
или входные данные для будущей работы проходят через обычную очередь.
Метод защищённый и вызывается слушателем внутри наследника контроллера.
