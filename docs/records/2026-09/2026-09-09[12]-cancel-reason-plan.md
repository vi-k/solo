# План

`CancelReason` становится открытой абстрактной основой с `name` для
журнала. У ядра отдельные `ManualCancelReason`, `ParentCancelReason`,
`HandlerCancelReason`; у `solo` — `RulesCancelReason`, `ClosedCancelReason`
под общей основой `SoloCancelReason`. Строковое равенство удаляется:
потребитель проверяет тип, payload сравнивает сам.

Пользовательский класс может хранить ошибку, стек и любые другие поля.
`cancel(reason: ...)` передаёт его без копирования. Явная причина из
`throw Cancelled.by(...)` сохраняется; обычный `throw Cancelled(...)`
остаётся `HandlerCancelReason`. При каскаде и распространении отмены
ребёнка тип обозначает путь, а поле `cause` сохраняет исходный `Cancelled`.
Отказы, удержание отмены, порядок и маршруты ошибок не меняются.
