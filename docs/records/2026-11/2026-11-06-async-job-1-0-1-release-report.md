# Выпуск async_job 1.0.1

По слову владельца 2026-11-06 «делай патч». Слово понято как подготовка, как
«давай патч» у `async_job_lints` 0.1.1: разрешение на связку приходит отдельным
запросом, состоящим только из просьбы опубликовать. Патч ждал слова владельца

## Что в патче

Код `lib/` с 1.0.0 не менялся: `git diff async_job-v1.0.0` по `lib/` пуст.
Патч — документация, примеры и тесты:

- README — короткий вход: Quick start и раздел «Walking away from a call»,
  а «Why» и «A fuller example» на странице «Why a job», таблица контекста
  и «Four words» на «Reference», — `2026-11-05-core-readme-entry-plan.md`;
- README называет плагин анализатора `async_job_lints` в «Install»;
- «A deadline for one step» страницы `time.md` первым в ветке, которая ловит
  срок ребёнка, вызывает `ctx.check()`;
- абзац страницы «With riverpod and bloc» о том, что обработчику bloc с одним
  вызовом задача не нужна, и имя правила `bare_await` пакета `async_job_lints`
  на «Cleanup rules». Этих двух в разделе «Unreleased» не было; подготовка
  дописала их в список изменений и в перевод.

Страница ядра о bloc появилась и снята 2026-11-04, между выпусками: в архиве
1.0.0 её не было, в 1.0.1 нет, и список изменений о ней молчит.
