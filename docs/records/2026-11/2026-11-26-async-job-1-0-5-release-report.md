# Выпуск async_job 1.0.5

По слову владельца 2026-11-26 «готовь выпуск async_job 1.0.5». Слово понято как
подготовка: разрешение на связку приходит отдельным запросом, состоящим только
из просьбы опубликовать.

## Что в патче

Одна правка `lib/` после 1.0.4: `git diff async_job-v1.0.4` по `lib/` — только
ветка в `job_context.dart`, коммит `10575b00`. Вызов `ctx.abandonable`, чью
задачу движок кончает руками, пока её отмена идёт к детям, бросает эту отмену,
когда приходит значение, а не `StateError`. Раньше тело, которое её не ловило,
отдавало ошибку в `onError` и в зону. Решение владельца 2026-11-26; строка
в списке изменений была под «Unreleased» с того же коммита.

Остальное после 1.0.4 — тесты и `.pubignore`: с `efc0d04d` каталог `tool/`
пакета в архив не попадает.

Не тронуто: тело ждёт, пока действие вернёт значение, хотя dartdoc
`abandonable` обещает конец ожидания с приходом отмены.

## Зависимости и порядок

`solo` держит ядро в `>=1.0.0 <1.1.0`, `async_job_lints` и `solo_lints` —
в `^1.0.0`; патч они получают сами. У самого ядра оверрайдов нет.

Оверрайды семи пакетов выше ядра на `async_job` из дерева вернул `f7655a3b`,
первая строка каждого — «Until async_job 1.0.5 is published.». В архив ядра они
не входят, поэтому снимаются после публикации, своим коммитом, как `9e90db32`
после 1.0.0. Ни одному пакету выше правка не нужна: нижнюю границу никто
не поднимает.

ни локально, ни в origin. Связка — релизный коммит «Release async_job 1.0.5»,
