# План: регистрация уведомления об отмене

Цель: `void Function() whenCancelled(void Function(Cancelled) callback)`.
Контракт согласован в диалоге: синхронный однократный вызов с причиной,
немедленный вызов при поздней подписке, функция отписки, отсутствие вызова
после `Done`/`Failed`. Ошибки идут маршрутом `ctx.onCancel`:
наблюдателю, а без него в зону; `Cancelled` без наблюдателя подавляется.
Асинхронный обработчик не ожидается. Регистрация не наблюдает исход.

Работа в `main`, без публикации. Выполнение в текущей сессии; перед
коммитом независимое ревью по `superpowers:requesting-code-review`.
