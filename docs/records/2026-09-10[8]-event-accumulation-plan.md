# План реализации

Цель: `collect` и `accumulate` в `SoloBase` с правилами `adjacent`,
`replace`, `join`. Спека: `2026-09-10[7]-event-accumulation-design.md`.
Стек: Dart, `FakeAsync`, `Completer`, существующий движок `solo`.
Выполнение в текущей сессии; процесс `subagent-driven-development`.
План и отчёт служат постоянным журналом вместе с handoff.

## Общие ограничения

- Работа в `main`, без PR, push и публикации по `AGENTS.md`.
- Состояние меняет обработчик через `ctx.emit`; внешняя запись
  состояния при приёме событий запрещена.
- Ядро `async_job` и обычный `Policy` не расширяются для накопителей.
- Рабочий тип, правила, контекст, дети, уборка и исходы — обычные у `solo`.
- Список передаётся при замене владением, без полного копирования;
  неизменяемый снимок создаётся один раз перед выполнением.
- Объект накопителя не хранит ссылки на завершённые группы.
- Документы и переводы меняются вместе; ширина Markdown 79 символов.
- Реализацию и документацию сохранять одним логическим коммитом.
  Промежуточные ревью выполняются по сохранённому diff рабочего дерева.

  ```dart

  final calls = <List<int>>[];

    calls.add(values);
    ctx.emit(values.length);
  });
  final a = events.add(1);
  final b = events.add(2);
  expect(identical(a, b), isTrue);
  ```
