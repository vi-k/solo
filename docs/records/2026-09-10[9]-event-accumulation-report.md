# Реализация и покрытие

`SoloBase.collect` и `SoloBase.accumulate` создают стабильный
`SoloAccumulator<E, T>`. Общий алгоритм `_SoloAccumulator` выбирает
группу по идентичности и `AccumulationPolicy`, проверяет повторный вход
и завершает замену до колбэков отмены. Данные хранятся в
`_AccumulationGroup`; при извлечении список получает неизменяемый снимок,
при передаче в handler и завершении служебное хранилище очищается.
При `replace` список передаётся владением, без полного копирования.

Критерии 1–19 спеки покрыты тестами: оба хранилища и все правила,
состояние между группами, общий или новый хэндл, nullable, ошибки
и повторный вход `merge`, изменение очереди из колбэка, границы старта,
рабочий тип и правила, отмена, дети и уборка, очистка и закрытие,
обычные политики и наблюдение ошибок. Замена проверена в 16 сочетаниях
хранилища, хука и повторного действия; пакет из 10 000 событий проверяет
сохранность и порядок. Освобождение данных проверено через test-only
`dart:mirrors`, без недетерминированной сборки мусора или порога времени.
Production-код не зависит от mirrors и не содержит API для тестов.

Проверка локальных ссылок выявила прежнюю битую ссылку на пример
в русском README `solo`. Она исправлена на `example`, как в оригинале;
ссылки обоих README и нового рецепта проверены.

## Найдено при реализации: повторный вход из диагностики отмены

`_SoloJob.cancelWith` вызывал отладочную диагностику до удаления
ожидающей задачи из очереди. Вызов `add` накопителя из диагностики
получал прежний хэндл; внешняя отмена затем завершала его вместе
с добавленным событием. Тест `cancellation diagnostics add to a new
group` воспроизвёл RED на идентичности хэндлов.

Вердикт: исправлено. Удаление перенесено до диагностики принятой отмены;
новое событие получает новую группу и исполняется. Обычный ожидающий
`Job` теперь также виден в этом колбэке с `isQueued: false`.
Проверка отказа отмене остаётся до удаления; причины, исходы, правила
работающей задачи и обычные политики не изменены. Регрессия GREEN,
после исправления пройден полный пакет `solo`.
