# Контракт

`ctx.each(stream, (child, event) { ... })` сразу запускает дочерний
`Job<void>` и возвращает его. Ожидание результата — через `.value`,
наблюдение исхода — через `.done`, отдельная отмена — через `.cancel()`.
Родитель ждёт ребёнка даже после возврата своего тела. Принятая отмена
родителя передаётся ребёнку; отдельная отмена ребёнка сама родителя
не помечает. Неперехваченный `Cancelled` из `.value` следует обычным
правилам исходов дочернего `Job`.

Подписка снимается сразу при принятой отмене ребёнка. Новые события
не доставляются; уже начатый обработчик ожидается перед завершением
ребёнка и его уборкой. Обработчик получает контекст ребёнка и реагирует
на отмену через его контрольные точки. Голый `await` по-прежнему нельзя
прервать; ожидание самого ребёнка из его обработчика замкнёт цикл.

Сохраняются порядок событий, ожидание асинхронного обработчика, буфер
событий из `onListen`, остановка после первой ошибки. Future от отмены
подписки по-прежнему не ожидается: это уборка источника. Обычный конец
потока зависит от того, когда источник вызовет `onDone`.

# Устройство

`each` становится методом `JobContext`. Реализация `JobContextBase`
создаёт ребёнка через защищённый `createEachJob` и запускает через `run`.
Алгоритм подписки остаётся в `job_stream.dart`, приватной части библиотеки
`job_base.dart`. Отдельного публичного `JobStream` больше нет.

`SoloContext.each` уточняет тип аргумента обработчика до
`SoloContext<S, W>`. Фабрика ребёнка у `solo` создаёт принадлежащий тому же
контроллеру `SoloJob`, сохраняя `W` и `keepWhile`. `canStart` родителя
повторно не наследуется: это условие запуска самого родителя. Ребёнок
отменяем независимо от настройки `cancellable` родителя. Проверки
владения обычного `run` не ослабляются. Описание ребёнка — `each`, ключ
не задан.

Ошибки и уведомления следуют обычному жизненному циклу `Job`: наблюдатель
видит отдельного ребёнка; `.ignore()` не подавляет `onError`. Вызов
`each` из `unattended`, после тела или при уборке отвергается, как запуск
любого ребёнка. Синхронные ошибки запуска бросаются из вызова `each`.
