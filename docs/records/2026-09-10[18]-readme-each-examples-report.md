# Примеры each в README

Владелец отметил, что описание each без примеров трудно понять.
В README async_job и его русском переводе появился отдельный раздел
обработки потоков. Примеры объясняют два сценария:

- saveMessages последовательно вызывает асинхронное сохранение каждого
  сообщения, используя контекст дочернего Job. Ожидание processing.value
  передаёт ошибки вызывающему коду.
- watchTicks печатает события периодического потока, отдельно отменяет
  дочерний Job и продолжает родительское тело. Пример показывает,
  что отмена ребёнка сама не отменяет родителя.

Существующие условия ожидания детей, отмены, ошибок и уборки сохранены.
Публичный API и реализация не менялись.
