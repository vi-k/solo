Обновлено: 2026-09-02.

## Где мы

Пакет `conveyor` 1.0.0 (нигде не опубликован, потребителей нет)
переделывается в пакет `solo`: то же ядро последовательных задач с
гарантией монопольного владения состоянием, но с новым публичным API на
обычных `async`-функциях вместо генераторов. Рядом появится
`packages/flutter_solo` с `ValueListenable`-лицом.

Фаза: **дизайн согласован, открытые вопросы решены, репозиторий переведён
в монорепозиторий. Следующий шаг — план реализации.**

Спецификация: `docs/records/2026-09-02[1]-solo-design.md`. Все секции
подтверждены владельцем в диалоге, включая иерархию `SoloBase` → `Solo` →
`SoloListenable`, модификаторы классов и решения раздела 11. Владелец
целиком документ не перечитывал; правки, если будут, вносятся в план.

Решения владельца от 2026-09-02: первая версия `solo` — `1.0.0`;
монорепозиторий с `packages/solo` и `packages/flutter_solo`; папку
репозитория владелец переименует в `solo` сам между сессиями.

Код в `packages/solo/lib/` — старая реализация `conveyor` 1.x. Она рабочая и
служит источником семантики для переноса, но публичный API будет заменён
целиком. `pubspec.yaml` пока называет пакет `conveyor` — переименование в
`solo` версии `1.0.0` это первый шаг плана, вместе с ним меняются импорты
в тестах.
